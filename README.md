PhenolWeb - 个人技术博客

一个基于 Vue 3 + Vite 构建的个人技术博客

🌐 在线访问
博客地址： https://phenoler.github.io

✨ 特性
🚀 现代技术栈 - Vue 3 + Vite + Pinia

📱 响应式设计 - 完美适配桌面和移动设备

🎨 优雅界面 - 简洁美观的用户体验

⚡ 极速加载 - Vite 构建，快速热重载

📝 Markdown 支持 - 原生支持技术文章写作

🌙 主题系统 - 支持亮色/暗黑主题切换

🛠️ 技术栈
前端框架

Vue 3.5

Vue Router 4

Pinia (状态管理)

构建工具

Vite 7.0

Rolldown (快速构建)

样式与UI

SCSS

CSS Variables

响应式布局

功能库

Axios (HTTP请求)

Marked (Markdown解析)

Highlight.js (代码高亮)

🚀 快速开始
环境要求
Node.js >= 20.19.0

npm >= 9.0.0

安装依赖
bash
npm install
开发模式
bash
npm run dev

生产构建
bash
npm run build
预览生产版本
bash
npm run preview
📦 部署
一键部署到 GitHub Pages
bash
npm run deploy
部署流程
代码推送到 master 分支

运行 npm run deploy 构建并部署到 main 分支

GitHub Pages 自动从 main 分支发布
